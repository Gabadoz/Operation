## 1. Pendahuluan

### Mengenal Artix Linux
**Artix Linux** adalah distribusi sistem operasi berbasis Arch Linux independen yang menerapkan model rilis bergulir (*rolling-release*). Ciri khas utama Artix Linux adalah **tidak menggunakan systemd** sebagai *init system* dan pengawas proses (PID 1), melainkan menyediakan alternatif tradisional UNIX yang ringan, cepat, deterministik, dan modular.

### Pilihan Sistem Init
Artix Linux mendukung empat sistem *init* resmi:
1. **OpenRC**: Sistem init berbasis dependensi (*dependency-based*) yang awalnya dikembangkan oleh proyek Gentoo Linux. Sangat populer, stabil, dan mudah dikonfigurasi.
2. **runit**: Sistem init dan supervisor proses UNIX yang sangat ringan, cepat, dan berprinsip sederhana (memakai symlink di `/etc/runit/runsvdir/default`).
3. **dinit**: Sistem init modern berbasis relasi layanan (*service dependency manager*) yang ditulis dalam C++ dengan performa boot sangat tinggi.
4. **s6**: Rangkaian modular pengawasan proses UNIX yang aman, efisien, dan andal (menggunakan `s6-linux-init` dan `s6-rc`).

> **Rekomendasi Pemula:** Pilih varian **OpenRC** atau **runit** karena ketersediaan dokumentasi dan skrip layanan pendukung yang paling melimpah di komunitas.

### Media Instalasi ISO (Base vs GUI)
Sesuai dokumentasi resmi Artix Wiki:
- **Fleksibilitas Init**: Anda dapat menginstal sistem init apa pun (OpenRC, runit, s6, atau dinit) dari citra ISO mana pun.
- **Base vs Non-Base**: Anda dapat melakukan instalasi dasar (*base install*) melalui terminal dari dalam ISO ber-desktop (seperti XFCE atau KDE). Cara ini sangat direkomendasikan bagi pemula karena Anda langsung memperoleh jaringan otomatis dan peramban web bawaan untuk membaca dokumentasi selama proses instalasi.

### Perbedaan Perintah: Artix Linux vs Arch Linux
Karena Artix tidak menggunakan infrastruktur systemd, beberapa tool bawaan Arch Linux digantikan oleh paket `artools`:

| Fungsi | Arch Linux (Baku) | Artix Linux (`artools`) |
| :--- | :--- | :--- |
| **Instalasi Paket Dasar** | `pacstrap /mnt ...` | `basestrap /mnt ...` (opsi `-i` untuk interaktif) |
| **Generate fstab** | `genfstab -U /mnt >> ...` | `fstabgen -U /mnt >> ...` (atau `-L` untuk label) |
| **Pindah Lingkungan Root** | `arch-chroot /mnt` | `artix-chroot /mnt` (sebelumnya `artools-chroot`) |
| **Manajemen Layanan** | `systemctl enable/start` | Sesuai init: `rc-update`/`rc-service`, `sv`, `dinitctl`, `s6` |

## 2. Persiapan Pra-Instalasi

### Unduh File ISO
Unduh citra ISO resmi Artix Linux melalui situs resmi: [https://artixlinux.org/download.php](https://artixlinux.org/download.php).
Pilih arsitektur `x86_64` dengan sistem init yang Anda inginkan (misal `artix-base-openrc-...iso` untuk instalasi CLI minimal, atau varian XFCE/KDE untuk live GUI).

### Membuat Media Bootable (USB Flashdrive)

#### Menggunakan Linux (`dd`):
Pastikan Anda mengetahui letak drive USB target (contoh `/dev/sdX`):
```bash
sudo dd bs=4M if=/path/to/artix-image.iso of=/dev/sdX status=progress oflag=sync
```

#### Menggunakan Windows:
- **Ventoy**: Cukup pasang Ventoy ke USB flashdrive, lalu salin berkas `.iso` Artix ke dalamnya.
- **Rufus**: Pilih ISO Artix, pilih skema partisi (GPT untuk UEFI), dan jika muncul dialog prompt, pastikan memilih mode **Write in DD Image mode**.

### Boot ke Media Instalasi
1. Tancapkan USB ke komputer target.
2. Nyalakan komputer dan tekan tombol boot menu (*Boot Menu Key*, biasanya `F12`, `F11`, `F9`, `F8`, atau `Esc` tergantung motherboard).
3. Pilih USB drive yang telah dibuat.
4. Masuk ke prompt shell Zsh dengan akun default `artix` (kata sandi: `artix`).
5. Beralihlah ke hak akses `root` untuk memulai proses instalasi:
   ```bash
   su -
   ```

## 3. Konfigurasi Lingkungan Live

### 3.1 Menyesuaikan Tata Letak Keyboard (Live)
Secara default tata letak keyboard adalah US (`us`). Jika Anda menggunakan tata letak lain:
```bash
# Daftar layout yang tersedia (secara rekursif)
ls -R /usr/share/kbd/keymaps

# Muat layout yang diinginkan tanpa menyertakan ekstensi berkas (contoh: us)
loadkeys us
```
> **Catatan Wiki:** Perintah `loadkeys` hanya berlaku pada terminal (tty) aktif saat ini hingga sistem direstart. Untuk konfigurasi permanen, Anda akan mengonfigurasi `/etc/conf.d/keymaps` (OpenRC) atau `/etc/vconsole.conf` (runit, s6, dinit) di dalam sistem target.

*(Opsional)* Jika font konsol terlalu kecil pada layar monitor resolusi tinggi (HiDPI):
```bash
setfont latarcyrheb-sun32
```

### 3.2 Memeriksa Mode Boot (UEFI vs BIOS)
Periksa apakah mesin Anda berjalan pada mode UEFI atau BIOS Legacy:
```bash
ls /sys/firmware/efi/efivars
```
- Jika direktori tersebut **ada dan menampilkan daftar berkas**, sistem berjalan dalam mode **UEFI**.
- Jika muncul pesan error *"No such file or directory"*, sistem berjalan dalam mode **BIOS / Legacy MBR**.

### 3.3 Menghubungkan ke Internet & Penamaan Antarmuka Tradisional
Berbeda dengan distribusi Linux berbasis systemd yang menerapkan penamaan antarmuka prediktif (seperti `enp3s0` atau `wlp2s0`), **Artix Linux mempertahankan penamaan antarmuka tradisional UNIX**:
- **Loopback**: `lo`
- **Ethernet (Kabel)**: `eth0`, `eth1`, ...
- **Wireless (Wi-Fi)**: `wlan0`, `wlan1`, ...

#### Koneksi Kabel (Ethernet)
Jika Anda menggunakan kabel LAN, koneksi umumnya otomatis aktif via DHCP pada media instalasi. Uji koneksi dengan:
```bash
ping -c 3 artixlinux.org
```

#### Koneksi Nirkabel (WiFi via ConnMan)
ISO Artix menjalankan daemon `connman` secara otomatis. Gunakan `connmanctl`:
```bash
connmanctl
```
Di dalam prompt interaktif `connmanctl`:
```text
connmanctl> enable wifi
connmanctl> scan wifi
connmanctl> services
```
Catat string identitas jaringan WiFi target Anda (contoh: `wifi_123456789abc_4d7957694669_managed_psk`).
```text
connmanctl> agent on
connmanctl> connect <string_layanan_wifi>
```
Masukkan kata sandi saat diminta, lalu keluar:
```text
connmanctl> quit
```
Uji kembali koneksi internet Anda:
```bash
ping -c 3 artixlinux.org
```
*(Alternatif: Anda juga dapat menggunakan kombinasi `wpa_supplicant` atau `iw` bersama `dhcpcd`).*

### 3.4 Sinkronisasi Jam Sistem (NTP)
Jalankan daemon NTP pada lingkungan live agar jam sistem tersinkronisasi sebelum memasang paket.

> **Catatan Penting Media ISO:** Pada media ISO Artix mingguan (*Weekly ISO*), Artix telah beralih dari `openntpd` ke `chrony`. Jalankan perintah sesuai daemon yang aktif di ISO Anda:

- **Pada ISO OpenRC:**
  ```bash
  rc-service ntpd start
  # atau jika ISO menggunakan chrony:
  rc-service chrony start
  ```
- **Pada ISO runit:**
  ```bash
  sv up openntpd
  # atau jika ISO menggunakan chrony:
  sv up chrony
  ```
- **Pada ISO dinit:**
  ```bash
  dinitctl start ntpd
  # atau jika ISO menggunakan chrony:
  dinitctl start chrony
  ```
- **Pada ISO s6:**
  ```bash
  s6-rc -u change openntpd
  # atau jika ISO menggunakan chrony:
  s6-rc -u change chrony
  ```

## 4. Partisi dan Format Media Penyimpanan

### 4.1 Identifikasi Drive Penyimpanan
Gunakan perintah `lsblk` untuk melihat seluruh media penyimpanan yang terpasang:
```bash
lsblk
```
Catat nama drive target Anda (contoh: SATA SSD/HDD `/dev/sda` atau NVMe SSD `/dev/nvme0n1`).

> ⚠️ **Peringatan Keras:** Pastikan Anda memilih drive yang tepat. Tindakan mempartisi dan memformat akan menghapus seluruh data pada drive target secara permanen.

### 4.2 Skema Partisi yang Direkomendasikan

#### Skema UEFI (Tabel Partisi GPT)
| Partisi | Titik Pasang (Mount Point) | Tipe Partisi | Ukuran yang Disarankan |
| :--- | :--- | :--- | :--- |
| `/dev/sdX1` | `/boot/efi` | EFI System | Sekitar **512 MiB** |
| `/dev/sdX2` | `[SWAP]` | Linux swap | Ukuran RAM (misal 4G / 8G) |
| `/dev/sdX3` | `/` (Root) | Linux filesystem | Sisa kapasitas disk |
| `/dev/sdX4` | `/home` *(opsional)* | Linux filesystem | Sesuai kebutuhan data pengguna |

#### Skema BIOS / Legacy (Tabel Partisi MBR/DOS atau GPT)
- **Jika menggunakan tabel partisi DOS/MBR:**
  | Partisi | Titik Pasang (Mount Point) | Tipe Partisi | Ukuran yang Disarankan |
  | :--- | :--- | :--- | :--- |
  | `/dev/sdX1` | `[SWAP]` | Linux swap | Ukuran RAM |
  | `/dev/sdX2` | `/` (Root) | Linux filesystem | Sisa kapasitas disk |

- **Catatan BIOS dengan disk GPT:** Jika Anda menggunakan skema GPT pada sistem BIOS/Legacy, Anda **wajib** membuat partisi **BIOS Boot** sebesar **1 MiB** (tipe `BIOS boot` / `ef02`) tanpa filesystem di awal disk agar bootloader GRUB dapat diinstal.

### 4.3 Membuat Partisi dengan `cfdisk`
Gunakan utilitas visual berbasis terminal `cfdisk` (ganti `/dev/sda` sesuai drive Anda):
```bash
cfdisk /dev/sda
```
1. Jika disk masih baru, pilih tipe label disk:
   - Pilih **`gpt`** untuk mode UEFI (atau mode BIOS modern).
   - Pilih **`dos`** untuk mode BIOS klasik.
2. Gunakan menu **`[ New ]`** untuk membuat partisi baru dan tetapkan ukurannya.
3. Pilih **`[ Type ]`** untuk menyesuaikan tipe partisi (misal: *EFI System* untuk partisi boot UEFI, *Linux swap* untuk swap, dan *Linux filesystem* untuk root/home).
4. Pilih **`[ Write ]`**, ketik `yes` untuk menyimpan tabel partisi ke disk.
5. Pilih **`[ Quit ]`** untuk keluar.

### 4.4 Memformat Partisi dan Menetapkan Label
Dokumentasi resmi Artix Wiki sangat merekomendasikan penggunaan switch `-L` (Label) saat memformat agar partisi dapat diidentifikasi secara konsisten melalui `/dev/disk/by-label/` tanpa harus bergantung pada urutan nomor partisi.

Sesuaikan nama partisi (`/dev/sdaX`) dengan konfigurasi disk Anda:

1. **Format Partisi EFI (Hanya untuk UEFI):**
   Format sebagai FAT32 dan beri label `ESP`:
   ```bash
   mkfs.fat -F 32 /dev/sda1
   fatlabel /dev/sda1 ESP
   ```

2. **Format dan Aktifkan Partisi Swap:**
   ```bash
   mkswap -L SWAP /dev/sda2
   swapon /dev/disk/by-label/SWAP
   ```

3. **Format Partisi Root (`ext4`):**
   ```bash
   mkfs.ext4 -L ROOT /dev/sda3
   ```

4. **Format Partisi Tambahan *(Opsional)*:**
   - Partisi Home: `mkfs.ext4 -L HOME /dev/sda4`
   - Partisi Boot terpisah: `mkfs.ext4 -L BOOT /dev/sdaX`

### 4.5 Memasang (Mount) Partisi
Pasang partisi ke `/mnt` menggunakan label atau nama perangkat:

```bash
# 1. Pasang partisi Root
mount /dev/disk/by-label/ROOT /mnt

# 2. Buat direktori boot dan pasang partisi EFI (untuk mode UEFI)
mkdir -p /mnt/boot/efi
mount /dev/disk/by-label/ESP /mnt/boot/efi

# 3. Pasang partisi Home (jika dibuat)
# mkdir -p /mnt/home
# mount /dev/disk/by-label/HOME /mnt/home
```

## 5. Instalasi Sistem Dasar (Base System)

Artix Linux menggunakan utilitas `basestrap` untuk memasang paket ke direktori sistem baru di `/mnt`.

### 5.1 Memasang Paket Inti dan Sistem Init
Pilih **salah satu** perintah di bawah ini sesuai sistem *init* yang ingin Anda gunakan pada sistem target:

- **Opsi A: Menggunakan OpenRC (Disarankan untuk Pemula)**
  ```bash
  basestrap /mnt base base-devel openrc elogind-openrc
  ```

- **Opsi B: Menggunakan runit**
  ```bash
  basestrap /mnt base base-devel runit elogind-runit
  ```

- **Opsi C: Menggunakan dinit**
  ```bash
  basestrap /mnt base base-devel dinit elogind-dinit
  ```

- **Opsi D: Menggunakan s6**
  ```bash
  basestrap /mnt base base-devel s6-base elogind-s6
  ```

> **Tips Wiki:** Jika terjadi konflik paket elogind saat instalasi, gunakan opsi interaktif `-i`:
> ```bash
> basestrap -i /mnt base
> ```
> Sistem akan meminta Anda memilih varian `elogind` yang sesuai secara interaktif.

### 5.2 Memasang Kernel dan Firmware
Artix menyediakan 3 pilihan kernel resmi: `linux` (stabil terbaru), `linux-lts` (dukungan jangka panjang), dan `linux-zen` (dioptimalkan untuk performa desktop/gaming). Sangat direkomendasikan untuk selalu menyertakan `linux-firmware`:

```bash
# Menggunakan kernel standar:
basestrap /mnt linux linux-firmware

# ATAU jika memilih kernel LTS:
# basestrap /mnt linux-lts linux-firmware
```
*(Opsional)* Anda dapat sekaligus menyertakan teks editor dasar:
```bash
basestrap /mnt nano vim
```

### 5.3 Menghasilkan Tabel Partisi (fstab)
Gunakan utilitas `fstabgen` dengan opsi UUID (`-U`) atau Label (`-L`) agar pemetaan drive tetap konsisten:
```bash
fstabgen -U /mnt >> /mnt/etc/fstab
```
Periksa dan verifikasi berkas `/mnt/etc/fstab`:
```bash
cat /mnt/etc/fstab
```
Pastikan seluruh partisi (`/`, `/boot/efi`, swap, dan `/home` jika ada) tercantum dengan benar.

## 6. Masuk ke Lingkungan Sistem Baru (Chroot)

Pindahkan sesi terminal Anda ke dalam sistem instalasi baru menggunakan utilitas `artix-chroot`:
```bash
artix-chroot /mnt
```
Prompt shell Anda sekarang akan berada di dalam lingkungan sistem Artix Linux baru.

## 7. Konfigurasi Sistem Utama

### 7.1 Pengaturan Jam dan Zona Waktu
1. Tautkan zona waktu wilayah Anda ke `/etc/localtime` (contoh untuk Waktu Indonesia Barat / WIB):
   ```bash
   ln -sf /usr/share/zoneinfo/Asia/Jakarta /etc/localtime
   ```
   *(Gunakan `Asia/Makassar` untuk WITA atau `Asia/Jayapura` untuk WIT).*

2. Sinkronkan jam sistem ke jam perangkat keras (*Hardware Clock / RTC*):
   ```bash
   hwclock --systohc
   ```
   > **Catatan Wiki:** Perintah ini mengatur RTC ke format UTC secara default. Jika Anda melakukan dual-boot dengan Windows, sesuaikan registri Windows agar membaca RTC dalam UTC sesuai panduan Arch/Artix Wiki.

### 7.2 Lokalisasi dan Bahasa (Locale)
1. Pasang teks editor jika belum terpasang:
   ```bash
   pacman -S nano
   ```
2. Buka berkas `/etc/locale.gen`:
   ```bash
   nano /etc/locale.gen
   ```
3. Hilangkan tanda pagar (`#`) pada baris locale yang Anda butuhkan, misalnya:
   ```text
   en_US.UTF-8 UTF-8
   id_ID.UTF-8 UTF-8
   ```
4. Simpan (`Ctrl + O`, `Enter`) dan keluar (`Ctrl + X`).
5. Buat berkas locale sistem:
   ```bash
   locale-gen
   ```
6. Sesuai dokumentasi resmi Wiki Artix, variabel locale dibaca melalui `/etc/locale.conf` (yang di-source oleh `/etc/profile`) atau `/etc/bash/bashrc.d/artix.bashrc`:
   ```bash
   echo "LANG=en_US.UTF-8" > /etc/locale.conf
   echo "LC_COLLATE=C" >> /etc/locale.conf
   ```

### 7.3 Konfigurasi Keyboard Konsol Permanen
Setiap init system memiliki berkas konfigurasi tersendiri untuk tata letak keyboard konsol permanen:

- **Jika Anda Menggunakan OpenRC:**
  Buka dan atur `/etc/conf.d/keymaps`:
  ```bash
  nano /etc/conf.d/keymaps
  ```
  Tetapkan:
  ```ini
  keymap="us"
  ```

- **Jika Anda Menggunakan runit, s6, atau dinit:**
  Buat dan konfigurasikan berkas `/etc/vconsole.conf`:
  ```bash
  nano /etc/vconsole.conf
  ```
  Isi dengan konfigurasi standar:
  ```ini
  KEYMAP=us
  FONT=lat1-16
  FONT_MAP=8859-1_to_uni
  ```

### 7.4 Konfigurasi Hostname dan Tabel Jaringan Lokal
1. Buat nama mesin (*hostname*) Anda di `/etc/hostname`:
   ```bash
   echo "artix-box" > /etc/hostname
   ```

2. **Khusus OpenRC**, tambahkan juga hostname ke `/etc/conf.d/hostname`:
   ```bash
   echo 'hostname="artix-box"' > /etc/conf.d/hostname
   ```

3. Konfigurasikan tabel resolusi lokal pada berkas `/etc/hosts`:
   ```bash
   nano /etc/hosts
   ```
   Tambahkan baris berikut:
   ```text
   127.0.0.1        localhost
   ::1              localhost
   127.0.1.1        artix-box.localdomain  artix-box
   ```
   *(Jika mesin Anda memiliki alamat IP statis/permanen, gunakan IP tersebut sebagai pengganti `127.0.1.1`).*

### 7.5 Mengatur Kata Sandi Akun Root
Atur kata sandi untuk pengguna administrator (`root`):
```bash
passwd
```

### 7.6 Membuat Pengguna Biasa dan Akses Sudo
Sangat tidak disarankan menggunakan akun `root` untuk aktivitas komputasi harian. Buatlah akun pengguna standar (ganti `namauser` dengan username pilihan Anda):

```bash
# Buat akun pengguna baru
useradd -m -g users -G wheel,video,audio,input,power,storage,optical -s /bin/bash namauser

# Atur kata sandi pengguna
passwd namauser
```

Pasang paket `sudo`:
```bash
pacman -S sudo
```

Izinkan anggota grup `wheel` untuk mengeksekusi perintah administratif via sudo:
```bash
EDITOR=nano visudo
```
Cari baris berikut dan hilangkan tanda pagar (`#`) di depannya:
```text
%wheel ALL=(ALL:ALL) ALL
```
Simpan dan keluar.

## 8. Konfigurasi Manajemen Jaringan dan Layanan Init

### Mekanisme Khusus Aktivasi Layanan di Dalam Chroot
> ⚠️ **Catatan Krusial Wiki Artix:** Pada sistem init **runit**, **s6**, dan **dinit**, proses pengaktifan layanan saat masih berada di dalam lingkungan `chroot` memerlukan perintah khusus yang berbeda dengan sistem yang sudah booting normal. Hal ini terjadi karena daemon init belum aktif dan direktori `/run` (tmpfs) belum tersedia.

Pilihlah salah satu manajer jaringan berikut sesuai preferensi Anda:

---

### Pilihan 1: ConnMan (Rekomendasi Resmi Wiki Artix)
ConnMan adalah manajer koneksi default Artix Linux yang sangat ringan, modular, dan hemat memori.

- **Untuk OpenRC:**
  ```bash
  pacman -S connman-openrc connman-gtk
  rc-update add connmand default
  ```

- **Untuk runit:**
  ```bash
  pacman -S connman-runit connman-gtk
  # Buat symlink layanan langsung ke runsvdir default:
  ln -s /etc/runit/sv/connmand /etc/runit/runsvdir/default
  ```

- **Untuk s6:**
  ```bash
  pacman -S connman-s6 connman-gtk
  # Daftarkan layanan ke bundle default dan kompilasi ulang database s6:
  touch /etc/s6/adminsv/default/contents.d/connmand
  s6-db-reload
  ```

- **Untuk dinit:**
  ```bash
  pacman -S connman-dinit connman-gtk
  # Buat symlink langsung ke boot.d (atau gunakan flag offline):
  ln -s ../connmand /etc/dinit.d/boot.d/
  # Atau opsi alternatif: dinitctl --offline enable connmand
  ```

---

### Pilihan 2: NetworkManager (Alternatif Desktop Penuh)
Cocok bagi Anda yang akan menggunakan lingkungan desktop seperti GNOME atau KDE Plasma.

- **Untuk OpenRC:**
  ```bash
  pacman -S networkmanager networkmanager-openrc
  rc-update add NetworkManager default
  ```

- **Untuk runit:**
  ```bash
  pacman -S networkmanager networkmanager-runit
  ln -s /etc/runit/sv/NetworkManager /etc/runit/runsvdir/default
  ```

- **Untuk s6:**
  ```bash
  pacman -S networkmanager networkmanager-s6
  touch /etc/s6/adminsv/default/contents.d/NetworkManager
  s6-db-reload
  ```

- **Untuk dinit:**
  ```bash
  pacman -S networkmanager networkmanager-dinit
  ln -s ../NetworkManager /etc/dinit.d/boot.d/
  # Atau opsi alternatif: dinitctl --offline enable NetworkManager
  ```

---

### Pilihan 3: dhcpcd & wpa_supplicant (Klien Minimalis)
Pilihan minimalis bagi server atau pengguna CLI/tiling window manager:
```bash
# Pasang paket inti dan skrip init sesuai init Anda:
# Ganti <init> dengan openrc / runit / s6 / dinit
pacman -S dhcpcd dhcpcd-<init> wpa_supplicant wpa_supplicant-<init>
```
Aktifkan layanan `dhcpcd` menggunakan metode yang sesuai dengan init Anda di atas.

---

### Pilihan 4: Gentoo netifrc (Khusus Pengguna OpenRC)
OpenRC mendukung modul `netifrc` untuk manajemen konfigurasi jaringan statis maupun DHCP per antarmuka:
```bash
pacman -S netifrc

# Periksa nama pasti antarmuka Anda (contoh: eth0)
ip -s link

# Tambahkan baris konfigurasi ke /etc/conf.d/net
echo 'config_eth0="dhcp"' >> /etc/conf.d/net

# Buat symlink skrip layanan per antarmuka dan aktifkan saat boot
ln -s /etc/init.d/net.lo /etc/init.d/net.eth0
rc-update add net.eth0 default
```

---

### Tabel Perintah Layanan (Chroot vs Sistem Berjalan)
Gunakan tabel referensi berikut untuk memahami perbedaan pengelolaan layanan:

| Init System | Saat Berada di Lingkungan Chroot (Instalasi) | Saat Sistem Sudah Booting Normal |
| :--- | :--- | :--- |
| **OpenRC** | `rc-update add <layanan> default` | `rc-service <layanan> start` / `rc-update add <layanan> default` |
| **runit** | `ln -s /etc/runit/sv/<layanan> /etc/runit/runsvdir/default` | `sv up <layanan>` / `sv down <layanan>` |
| **dinit** | `ln -s ../<layanan> /etc/dinit.d/boot.d/`<br>*(atau `dinitctl --offline enable <layanan>`)* | `dinitctl start <layanan>`<br>`dinitctl enable <layanan>` |
| **s6** | `touch /etc/s6/adminsv/default/contents.d/<layanan>`<br>`s6-db-reload` | `s6 live start <layanan>`<br>`s6 set enable <layanan> && s6 set commit && s6 live install` |

## 9. Instalasi Bootloader (GRUB)

### 9.1 Instalasi Microcode Processor
Pasang paket pembaruan mikrokode sesuai produsen prosesor Anda untuk stabilitas dan keamanan CPU:
- **Pengguna Intel:**
  ```bash
  pacman -S intel-ucode
  ```
- **Pengguna AMD:**
  ```bash
  pacman -S amd-ucode
  ```

### 9.2 Instalasi GRUB pada Mode UEFI
Pasang paket GRUB, efibootmgr, dan os-prober:
```bash
pacman -S grub efibootmgr os-prober
```

Pasang GRUB ke partisi EFI:
```bash
grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=grub
```

### 9.3 Instalasi GRUB pada Mode BIOS/Legacy
Pasang paket GRUB dan os-prober:
```bash
pacman -S grub os-prober
```

Pasang GRUB ke Master Boot Record (MBR) drive (tulis drive utama tanpa nomor partisi, contoh `/dev/sda`):
```bash
grub-install --recheck /dev/sda
```

### 9.4 Membuat File Konfigurasi GRUB
Jika Anda memiliki sistem operasi lain di komputer yang sama (seperti Windows), izinkan `os-prober` dengan mengedit `/etc/default/grub`:
```bash
nano /etc/default/grub
```
Pastikan baris berikut aktif (tanpa tanda pagar di depannya):
```text
GRUB_DISABLE_OS_PROBER=false
```

Hasilkan berkas konfigurasi `grub.cfg`:
```bash
grub-mkconfig -o /boot/grub/grub.cfg
```
> Pastikan output menampilkan bahwa citra kernel (`vmlinuz-linux`), initramfs, dan microcode berhasil terdeteksi.

## 10. Manajemen Repositori Artix dan Arch Linux

### Struktur Repositori Resmi Artix
Artix Linux mengelola repositori independen yang sepenuhnya bebas dari dependensi systemd:
- **`[system]`**: Repositori paket dasar inti Artix. **Menggantikan sepenuhnya repositori `[core]` milik Arch Linux.**
- **`[world]`**: Repositori paket utilitas dan aplikasi umum (setara dengan `[extra]` di Arch).
- **`[galaxy]`**: Repositori paket kurasi Artix yang tidak memiliki analogi langsung di Arch (seperti `archlinux-keyring`, `libreoffice`, driver, dll).
- **`[lib32]`**: Repositori pustaka kompatibilitas 32-bit (setara dengan `[multilib]` di Arch).

### Peringatan Keras Repositori Arch [core]
> ⚠️ **PERINGATAN FATAL WIKI ARTIX:**
> **JANGAN PERNAH MENGAKTIFKAN REPOSITORI `[core]` MILIK ARCH LINUX!**
> Repositori `core` Arch Linux berisi paket-paket yang memiliki ketergantungan wajib pada systemd (seperti `systemd-sysvcompat`). Mengaktifkannya dijamin akan merusak (*break*) sistem Artix Anda secara menyeluruh.

### Aturan Urutan Repositori (Precedence)
Repositori resmi Artix **HARUS SELALU BERADA DI ATAS** repositori pihak ketiga atau repositori resmi Arch Linux dalam berkas `/etc/pacman.conf`. Hal ini memastikan bahwa pacman akan selalu memprioritaskan paket versi bebas-systemd dari Artix.

### Mengaktifkan Repositori Arch Linux [extra] dan [multilib]
Semua repositori Arch Linux dinonaktifkan secara default. Jika Anda membutuhkan paket perangkat lunak yang belum tersedia di repositori Artix, aktifkan repositori `[extra]` dan `[multilib]` dengan cara:

1. Pasang paket pendukung dari repositori `[galaxy]`:
   ```bash
   pacman -S artix-archlinux-support
   ```

2. Buka berkas `/etc/pacman.conf`:
   ```bash
   nano /etc/pacman.conf
   ```

3. Pastikan struktur repositori Anda tersusun rapi seperti contoh berikut:
   ```ini
   # Repositori Resmi Artix (Harus Di Atas)
   [system]
   Include = /etc/pacman.d/mirrorlist

   [world]
   Include = /etc/pacman.d/mirrorlist

   [galaxy]
   Include = /etc/pacman.d/mirrorlist

   [lib32]
   Include = /etc/pacman.d/mirrorlist

   # Repositori Resmi Arch Linux (Diletakkan di Bawah Repositori Artix)
   [extra]
   Include = /etc/pacman.d/mirrorlist-arch

   [multilib]
   Include = /etc/pacman.d/mirrorlist-arch
   ```

4. *(Opsional)* Jika memerlukan mirrorlist Arch Linux terbaru:
   ```bash
   wget https://archlinux.org/mirrorlist/all/ -O /etc/pacman.d/mirrorlist-arch
   ```

5. Sinkronkan database paket:
   ```bash
   pacman -Sy
   ```

## 11. Finalisasi dan Reboot

Seluruh proses konfigurasi dasar telah selesai. Sekarang saatnya keluar dari lingkungan chroot dan melakukan booting pertama:

1. Keluar dari lingkungan chroot:
   ```bash
   exit
   ```

2. Lepaskan pemasangan (*unmount*) seluruh partisi di `/mnt`:
   ```bash
   umount -R /mnt
   ```

3. Matikan partisi swap:
   ```bash
   swapoff -a
   ```

4. Nyalakan ulang komputer:
   ```bash
   reboot
   ```

Cabut media instalasi USB Flashdrive saat komputer mulai melakukan restart. Komputer akan menyala dan masuk ke menu bootloader GRUB Artix Linux.

### Display Login Manager (DM)
Artix Linux secara resmi mendukung berbagai Display Manager seperti LightDM, SDDM, GDM, LXDM, dan XDM. Setiap display manager memiliki paket skrip init tersendiri (`<dm>-<init>`).

Contoh instalasi dan aktivasi **LightDM** (atau **SDDM**) pada sistem yang sudah aktif berjalan normal:

- **Pada OpenRC:**
  ```bash
  sudo pacman -S lightdm lightdm-gtk-greeter lightdm-openrc
  sudo rc-update add lightdm default
  ```

- **Pada runit:**
  ```bash

  ```

- **Pada dinit:**
  ```bash
  sudo pacman -S lightdm lightdm-gtk-greeter lightdm-dinit
  sudo dinitctl enable lightdm
  ```

- **Pada s6:**
  ```bash
  sudo pacman -S lightdm lightdm-gtk-greeter lightdm-s6
  sudo s6 set enable lightdm
  sudo s6 set commit
  sudo s6 live install
  ```

> **Alternatif Tanpa Display Manager:** Jika Anda ingin meluncurkan desktop secara manual tanpa DM melalui terminal (`startx`), buat berkas `~/.xinitrc` pada direktori home pengguna:
> ```bash
> echo "exec startxfce4" > ~/.xinitrc
> ```
