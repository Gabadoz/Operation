## 1. Pendahuluan

### Mengenal Artix Linux
**Artix Linux** adalah distribusi sistem operasi berbasis Arch Linux independen yang menerapkan model rilis bergulir (*rolling-release*). Ciri khas utama Artix Linux adalah **tidak menggunakan systemd** sebagai *init system* dan *service manager*, melainkan menyediakan alternatif tradisional yang ringan, cepat, dan modular.

### Pilihan Sistem Init
Artix Linux mendukung empat sistem *init* resmi:
1. **OpenRC**: Sistem init berbasis ketergantungan (*dependency-based*) yang awalnya dikembangkan oleh Gentoo Linux. Sangat populer, stabil, dan mudah dikonfigurasi.
2. **runit**: Sistem init dan supervisor proses UNIX yang sangat ringan, cepat, dan berprinsip sederhana.
3. **dinit**: Sistem init modern berbasis relasi layanan (*service dependency manager*) yang ditulis dalam C++.
4. **s6**: Kumpulan program pengawasan proses UNIX kecil yang aman, efisien, dan andal.

> **Rekomendasi pemula:** Pilih varian **OpenRC** atau **runit** karena ketersediaan dokumentasi dan skrip layanan pendukung yang paling melimpah.

### Perbedaan Perintah: Artix Linux vs Arch Linux
Karena Artix tidak menggunakan infrastruktur systemd, beberapa tool bawaan Arch Linux digantikan oleh tool dari paket `artools`:

| Fungsi | Arch Linux (Baku) | Artix Linux (`artools`) |
| :--- | :--- | :--- |
| **Instalasi Paket Dasar** | `pacstrap /mnt ...` | `basestrap /mnt ...` |
| **Generate fstab** | `genfstab -U /mnt >> ...` | `fstabgen -U /mnt >> ...` |
| **Pindah Lingkungan Root** | `arch-chroot /mnt` | `artix-chroot /mnt` |
| **Manajemen Layanan** | `systemctl enable/start` | Sesuai sistem init terpilih (`rc-service`, `rc-update`, `sv`, `dinitctl`, `s6-rc`) |

## 2. Persiapan Pra-Instalasi

### Unduh File ISO
Unduh citra ISO resmi Artix Linux melalui situs resmi: [https://artixlinux.org/download.php](https://artixlinux.org/download.php).
Pilih arsitektur `x86_64` dengan varian init yang Anda inginkan (misal: `artix-base-openrc-...iso` untuk instalasi CLI minimal, atau varian ber-desktop seperti XFCE/KDE jika ingin live GUI).

### Membuat Media Bootable (USB Flashdrive)

#### Menggunakan Linux (`dd`):
Pastikan Anda mengetahui letak drive USB Anda (contoh `/dev/sdX`):
```bash
sudo dd bs=4M if=/path/to/artix-image.iso of=/dev/sdX status=progress oflag=sync
```

#### Menggunakan Windows:
- **Ventoy**: Cukup format USB dengan Ventoy, lalu salin file `.iso` ke dalam partisi flashdrive.
- **Rufus**: Pilih ISO Artix, pilih skema partisi (GPT untuk UEFI), dan jika muncul dialog prompt, pilih mode **Write in DD Image mode**.

### Boot ke Media Instalasi
1. Tancapkan USB ke komputer target.
2. Nyalakan komputer dan tekan tombol pemilihan boot (*Boot Menu Key*, biasanya `F12`, `F11`, `F9`, `F8`, atau `Esc` tergantung motherboard).
3. Pilih USB drive yang telah dibuat.
4. Anda akan masuk ke prompt shell Zsh dengan akun default `artix` (kata sandi: `artix`).
5. Beralihlah ke hak akses `root` untuk memulai proses instalasi:
   ```bash
   su -
   ```

## 3. Konfigurasi Lingkungan Live

### 3.1 Menyesuaikan Tata Letak Keyboard
Secara default tata letak keyboard adalah US (`us`). Jika menggunakan tata letak lain:
```bash
# Daftar layout yang tersedia
ls /usr/share/kbd/keymaps/**/*.map.gz

# Muat layout yang diinginkan (contoh: us)
loadkeys us
```

*(Opsional)* Jika font konsol terlalu kecil di monitor beresolusi tinggi (HiDPI):
```bash
setfont latarcyrheb-sun32
```

### 3.2 Memeriksa Mode Boot (UEFI vs BIOS)
Periksa apakah mesin Anda berjalan pada mode UEFI atau BIOS Legacy:
```bash
ls /sys/firmware/efi/efivars
```
- Jika direktori tersebut **ada dan menampilkan daftar berkas**, sistem Anda berjalan dalam mode **UEFI**.
- Jika muncul pesan error *"No such file or directory"*, sistem Anda berjalan dalam mode **BIOS / Legacy MBR**.

### 3.3 Menghubungkan ke Internet

#### Koneksi Kabel (Ethernet)
Jika Anda menggunakan kabel LAN, koneksi umumnya otomatis aktif via DHCP. Uji koneksi dengan perintah:
```bash
ping -c 3 artixlinux.org
```

#### Koneksi Nirkabel (WiFi via ConnMan)
ISO instalasi Artix menjalankan daemon `connman` secara default. Untuk menghubungkan ke WiFi:
```bash
connmanctl
```
Di dalam antarmuka interaktif `connmanctl`:
```text
connmanctl> enable wifi
connmanctl> scan wifi
connmanctl> services
```
Catat string SSID layanan WiFi target Anda (contoh: `wifi_123456789abc_4d7957694669_managed_psk`).
```text
connmanctl> agent on
connmanctl> connect <string_layanan_wifi>
```
Masukkan kata sandi (*passphrase*) WiFi ketika diminta, lalu keluar:
```text
connmanctl> quit
```
Uji kembali koneksi:
```bash
ping -c 3 artixlinux.org
```

### 3.4 Sinkronisasi Jam Sistem
Jalankan layanan NTP agar jam sistem tersinkronisasi dengan server waktu jaringan:

- **Pada ISO OpenRC:**
  ```bash
  rc-service ntpd start
  ```
- **Pada ISO runit:**
  ```bash
  sv up ntpd
  ```
- **Pada ISO dinit:**
  ```bash
  dinitctl start ntpd
  ```
- **Pada ISO s6:**
  ```bash
  s6-rc -u change ntpd
  ```

## 4. Partisi dan Format Media Penyimpanan

### 4.1 Identifikasi Drive Penyimpanan
Gunakan perintah `lsblk` untuk melihat media penyimpanan yang terpasang:
```bash
lsblk
```
Perhatikan nama drive Anda, misalnya:
- NVMe SSD: `/dev/nvme0n1`
- SATA SSD / HDD: `/dev/sda`

> ⚠️ **Peringatan Penting:** Pastikan Anda memilih drive yang tepat. Tindakan mempartisi dan memformat akan menghapus seluruh data pada drive target.

### 4.2 Skema Partisi yang Direkomendasikan

#### Skema UEFI (Label GPT)
| Partisi | Titik Pasang (Mount Point) | Tipe Partisi | Ukuran yang Disarankan |
| :--- | :--- | :--- | :--- |
| `/dev/sdX1` | `/boot/efi` | EFI System | 512 MiB – 1024 MiB |
| `/dev/sdX2` | `[SWAP]` | Linux swap | Ukuran RAM (misal: 4G / 8G / 16G) |
| `/dev/sdX3` | `/` (Root) | Linux filesystem | Sisa kapasitas drive |

#### Skema BIOS / Legacy (Label MBR/DOS)
| Partisi | Titik Pasang (Mount Point) | Tipe Partisi | Ukuran yang Disarankan |
| :--- | :--- | :--- | :--- |
| `/dev/sdX1` | `[SWAP]` | Linux swap | Ukuran RAM |
| `/dev/sdX2` | `/` (Root) | Linux filesystem | Sisa kapasitas drive |

### 4.3 Membuat Partisi dengan `cfdisk`
Gunakan utilitas berbasis TUI `cfdisk` (ganti `/dev/sda` sesuai drive Anda):
```bash
cfdisk /dev/sda
```
- Jika drive masih kosong, pilih tipe label partisi:
  - Pilih **`gpt`** untuk mode UEFI.
  - Pilih **`dos`** untuk mode BIOS.
- Gunakan menu **`[ New ]`** untuk membuat partisi baru dan tentukan ukurannya.
- Pilih **`[ Type ]`** untuk mengubah tipe partisi:
  - Partisi boot UEFI: ubah tipe ke **EFI System**.
  - Partisi swap: ubah tipe ke **Linux swap**.
  - Partisi root: biarkan **Linux filesystem**.
- Pilih **`[ Write ]`**, ketik `yes` untuk menyimpan perubahan ke disk.
- Pilih **`[ Quit ]`** untuk keluar.

### 4.4 Memformat Partisi

Ganti penomoran partisi (`/dev/sdaX`) sesuai dengan konfigurasi partisi Anda:

1. **Format Partisi EFI (Hanya untuk UEFI):**
   ```bash
   mkfs.fat -F32 /dev/sda1
   ```

2. **Inisialisasi dan Aktifkan Partisi Swap:**
   ```bash
   mkswap -L SWAP /dev/sda2
   swapon /dev/sda2
   ```

3. **Format Partisi Root (`ext4`):**
   ```bash
   mkfs.ext4 -L ROOT /dev/sda3
   ```

### 4.5 Memasang (Mount) Partisi
Pasang partisi Root ke direktori `/mnt`:
```bash
mount /dev/sda3 /mnt
```

Untuk sistem **UEFI**, buat direktori `/mnt/boot/efi` dan pasang partisi EFI:
```bash
mkdir -p /mnt/boot/efi
mount /dev/sda1 /mnt/boot/efi
```

## 5. Instalasi Sistem Dasar (Base System)

Artix Linux menggunakan utilitas `basestrap` untuk memasang paket ke direktori sistem baru di `/mnt`.

### 5.1 Memasang Paket Inti dan Sistem Init
Pilih **salah satu** baris perintah di bawah ini sesuai sistem *init* yang ingin Anda gunakan pada sistem target:

- **Opsi A: Menggunakan OpenRC (Disarankan)**
  ```bash
  basestrap /mnt base base-devel openrc elogind-openrc
  ```

- **Opsi B: Menggunakan runit**
  ```bash
  basestrap /mnt base base-devel runit elogind-runit
  ```

- **Opsi C: Menggunakan dinit**
  ```bash
  basestrap /mnt base base-devel dinit elogind-dinit
  ```

- **Opsi D: Menggunakan s6**
  ```bash
  basestrap /mnt base base-devel s6-base elogind-s6
  ```

### 5.2 Memasang Kernel dan Firmware
Pasang kernel Linux, header, firmware perangkat keras, serta teks editor dasar:
```bash
basestrap /mnt linux linux-headers linux-firmware nano vim
```
> **Catatan:** Jika menginginkan stabilitas jangka panjang, Anda dapat menggunakan `linux-lts` dan `linux-lts-headers` sebagai pengganti atau pendamping paket `linux`.

### 5.3 Menghasilkan Tabel Partisi (fstab)
Gunakan utilitas `fstabgen` dengan opsi UUID (`-U`) agar sistem dapat memetakan drive secara konsisten:
```bash
fstabgen -U /mnt >> /mnt/etc/fstab
```

Periksa kebenaran file `/mnt/etc/fstab`:
```bash
cat /mnt/etc/fstab
```
Pastikan partisi Root (`/`), EFI (`/boot/efi`), dan Swap telah terdaftar dengan benar.

## 6. Masuk ke Lingkungan Sistem Baru (Chroot)

Pindahkan sesi terminal ke dalam sistem Artix Linux yang baru saja dipasang:
```bash
artix-chroot /mnt
```
Prompt terminal Anda sekarang akan berubah menandakan Anda sudah berada di dalam lingkungan root sistem baru.

## 7. Konfigurasi Sistem Utama

### 7.1 Pengaturan Zona Waktu
Tautkan zona waktu sistem Anda (contoh untuk Indonesia Bagian Barat / WIB):
```bash
ln -sf /usr/share/zoneinfo/Asia/Jakarta /etc/localtime
```
*(Gunakan `Asia/Makassar` untuk WITA atau `Asia/Jayapura` untuk WIT).*

### 7.2 Pengaturan Jam Perangkat Keras (Hardware Clock)
Sinkronkan jam sistem ke jam perangkat keras (*Real-Time Clock*):
```bash
hwclock --systohc
```

### 7.3 Lokalisasi dan Bahasa (Locale)
1. Buka file `/etc/locale.gen` dengan text editor:
   ```bash
   nano /etc/locale.gen
   ```
2. Hapus tanda pagar (`#`) pada baris locale yang ingin digunakan, misalnya:
   ```text
   en_US.UTF-8 UTF-8
   id_ID.UTF-8 UTF-8
   ```
3. Simpan dan keluar (pada nano: `Ctrl + O`, `Enter`, lalu `Ctrl + X`).
4. Hasilkan locale:
   ```bash
   locale-gen
   ```
5. Buat konfigurasi locale sistem di `/etc/locale.conf`:
   ```bash
   echo "LANG=en_US.UTF-8" > /etc/locale.conf
   ```

### 7.4 Konfigurasi Keyboard Konsol Permanen
Buat file konfigurasi `/etc/vconsole.conf` agar layout keyboard konsol tersimpan permanen:
```bash
echo "KEYMAP=us" > /etc/vconsole.conf
```

### 7.5 Konfigurasi Hostname dan Jaringan Lokal
1. Tentukan nama komputer (*hostname*) Anda (misal: `artix-box`):
   ```bash
   echo "artix-box" > /etc/hostname
   ```

2. Jika menggunakan **OpenRC**, perbarui juga `/etc/conf.d/hostname`:
   ```bash
   echo 'hostname="artix-box"' > /etc/conf.d/hostname
   ```

3. Konfigurasikan tabel pemetaan lokal di `/etc/hosts`:
   ```bash
   nano /etc/hosts
   ```
   Tambahkan baris berikut:
   ```text
   127.0.0.1   localhost
   ::1         localhost
   127.0.1.1   artix-box.localdomain artix-box
   ```

### 7.6 Mengatur Kata Sandi Akun Root
Atur kata sandi untuk akun administrator (`root`):
```bash
passwd
```

### 7.7 Membuat Pengguna Biasa dan Akses Sudo
Sangat tidak disarankan menggunakan akun `root` untuk aktivitas komputasi sehari-hari. Buatlah akun pengguna standar (ganti `namauser` dengan username pilihan Anda):
```bash
# Buat akun pengguna dan tambahkan ke grup wheel
useradd -m -g users -G wheel,video,audio,storage,optical -s /bin/bash namauser

# Atur kata sandi pengguna
passwd namauser
```

Pasang paket `sudo`:
```bash
pacman -S sudo
```

Izinkan anggota grup `wheel` untuk mengeksekusi perintah administratif via sudo:
```bash
EDITOR=nano visudo
```
Cari baris berikut dan hilangkan tanda pagar (`#`) di depannya:
```text
%wheel ALL=(ALL:ALL) ALL
```
Simpan dan keluar.

## 8. Konfigurasi Manajemen Jaringan dan Layanan

Pada Artix Linux, daemon layanan membutuhkan paket skrip init yang sesuai dengan init system yang Anda gunakan.

### Tabel Manajemen Layanan Berdasarkan Sistem Init

| Init System | Paket Tambahan Layanan | Perintah Menjalankan Layanan | Perintah Mengaktifkan saat Boot |
| :--- | :--- | :--- | :--- |
| **OpenRC** | `<layanan>-openrc` | `rc-service <layanan> start` | `rc-update add <layanan> default` |
| **runit** | `<layanan>-runit` | `sv up <layanan>` | `ln -s /etc/runit/sv/<layanan> /etc/runit/runsvdir/default/` |
| **dinit** | `<layanan>-dinit` | `dinitctl start <layanan>` | `dinitctl enable <layanan>` |
| **s6** | `<layanan>-s6` | `s6-rc -u change <layanan>` | `s6-rc-bundle-update add default <layanan>` |

### Menginstal dan Mengaktifkan NetworkManager

Pasang paket NetworkManager beserta skrip init yang sesuai dengan init pilihan Anda:

#### Jika Anda Memilih OpenRC:
```bash
pacman -S networkmanager networkmanager-openrc
rc-update add NetworkManager default
```

#### Jika Anda Memilih runit:
```bash
pacman -S networkmanager networkmanager-runit
ln -s /etc/runit/sv/NetworkManager /etc/runit/runsvdir/default/
```

#### Jika Anda Memilih dinit:
```bash
pacman -S networkmanager networkmanager-dinit
dinitctl enable NetworkManager
```

#### Jika Anda Memilih s6:
```bash
pacman -S networkmanager networkmanager-s6
s6-rc-bundle-update add default NetworkManager
```

## 9. Instalasi Bootloader (GRUB)

### 9.1 Instalasi Microcode Processor
Instal paket microcode yang sesuai dengan prosesor komputer Anda untuk stabilitas dan pembaruan keamanan CPU:
- **Pengguna Intel:**
  ```bash
  pacman -S intel-ucode
  ```
- **Pengguna AMD:**
  ```bash
  pacman -S amd-ucode
  ```

### 9.2 Instalasi GRUB pada Mode UEFI
Pasang paket GRUB dan utilitas EFI:
```bash
pacman -S grub efibootmgr os-prober
```

Pasang bootloader ke partisi EFI:
```bash
grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=grub
```

### 9.3 Instalasi GRUB pada Mode BIOS/Legacy
Pasang paket GRUB:
```bash
pacman -S grub os-prober
```

Pasang GRUB ke Master Boot Record (MBR) drive (tulis drive utama tanpa nomor partisi, contoh `/dev/sda`):
```bash
grub-install --target=i386-pc /dev/sda
```

### 9.4 Membuat File Konfigurasi GRUB
Hasilkan file konfigurasi `grub.cfg`:
```bash
grub-mkconfig -o /boot/grub/grub.cfg
```
> Pastikan output menampilkan bahwa citra kernel (`vmlinuz-linux`) dan initramfs berhasil dideteksi.

## 10. Mengaktifkan Repositori Arch Linux (Opsional)

Artix menyediakan repositori tersendiri untuk paket-paket non-systemd. Jika Anda memerlukan software tambahan dari repositori Arch Linux resmi (`extra` atau `multilib`), pasang paket integrasi:

```bash
pacman -S artix-archlinux-support
```

Buka `/etc/pacman.conf`:
```bash
nano /etc/pacman.conf
```
Tambahkan entri repositori Arch Linux di bagian paling bawah file:
```ini
# Repositori Arch Linux Resmi
[extra]
Include = /etc/pacman.d/mirrorlist-arch

[multilib]
Include = /etc/pacman.d/mirrorlist-arch
```

Sinkronkan database paket:
```bash
pacman -Sy
```

## 11. Finalisasi dan Reboot

Semua konfigurasi dasar sistem telah selesai dipasang. Sekarang saatnya keluar dan memulai ulang sistem:

1. Keluar dari lingkungan chroot:
   ```bash
   exit
   ```

2. Lepaskan pemasangan (*unmount*) seluruh partisi di `/mnt`:
   ```bash
   umount -R /mnt
   ```

3. Matikan partisi swap:
   ```bash
   swapoff -a
   ```

4. Mulai ulang sistem:
   ```bash
   reboot
   ```

Cabut media instalasi USB Flashdrive saat komputer sedang melakukan restart. Sistem akan menyala dan menampilkan menu GRUB Artix Linux.

## 12. Langkah Pasca-Instalasi

Setelah booting pertama kali, masuklah menggunakan username dan kata sandi yang telah Anda buat pada Langkah 7.7.

### Koneksi Jaringan
Gunakan utilitas CLI `nmtui` untuk mengelola koneksi WiFi dengan antarmuka grafis terminal yang mudah:
```bash
nmtui
```
Pilih **Activate a connection**, pilih SSID jaringan WiFi Anda, lalu masukkan kata sandi.

### Server Suara (PipeWire)
Instal stack audio modern berbasis PipeWire:
```bash
sudo pacman -S pipewire pipewire-pulse wireplumber alsa-utils
```

### Driver Grafis (GPU)
Instal driver yang sesuai dengan kartu grafis Anda:
- **Intel:**
  ```bash
  sudo pacman -S mesa vulkan-intel
  ```
- **AMD:**
  ```bash
  sudo pacman -S mesa xf86-video-amdgpu vulkan-radeon
  ```
- **NVIDIA (Proprietary):**
  ```bash
  sudo pacman -S nvidia nvidia-utils
  ```
- **VirtualBox Guest:**
  ```bash
  sudo pacman -S virtualbox-guest-utils
  ```

### Lingkungan Desktop (Desktop Environment)

#### Contoh: Memasang XFCE Desktop
1. Pasang server display Xorg dan komponen XFCE:
   ```bash
   sudo pacman -S xorg-server xfce4 xfce4-goodies
   ```

2. Pasang Display Manager (misalnya LightDM):
   - **Jika Anda menggunakan OpenRC:**
     ```bash
     sudo pacman -S lightdm lightdm-gtk-greeter lightdm-openrc
     sudo rc-update add lightdm default
     ```
   - **Jika Anda menggunakan runit:**
     ```bash
     sudo pacman -S lightdm lightdm-gtk-greeter lightdm-runit
     sudo ln -s /etc/runit/sv/lightdm /etc/runit/runsvdir/default/
     ```
   - **Jika Anda menggunakan dinit:**
     ```bash
     sudo pacman -S lightdm lightdm-gtk-greeter lightdm-dinit
     sudo dinitctl enable lightdm
     ```
   - **Jika Anda menggunakan s6:**
     ```bash
     sudo pacman -S lightdm lightdm-gtk-greeter lightdm-s6
     sudo s6-rc-bundle-update add default lightdm
     ```

3. Reboot komputer Anda (`sudo reboot`). Sistem akan otomatis masuk ke tampilan login LightDM dan siap digunakan!
